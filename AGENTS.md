# Project instructions

- Create and use a project-local virtual environment for optional Python tooling (`.venv`); never commit it.
- Use project-local Node dependencies and the pnpm lockfile. Do not install project packages globally.
- Keep all personal data, OAuth tokens, secrets, and backups out of this public repository.
- Do not deploy to GitHub Pages without explicit owner approval. Deployment stays manual.
- Run relevant tests and a production build before release. Never claim live Google OAuth passed without an actual configured client and account test.
